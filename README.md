# Playbooks

This repository contains short, practical playbooks for engineering teams using PulseOwl.

Each playbook provides a repeatable workflow for a specific maintenance or security task. The goal is to help teams move from identification to prioritisation, action, and resolution with clear and consistent steps.

## Playbooks

| Name                                                                                                          | Description                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| [PulseOwl Vulnerability Prioritisation Playbook](playbooks/pulseowl-vulnerability-prioritisation-playbook.md) | A practical workflow for identifying, assessing, prioritising, remediating, and resolving security vulnerabilities with PulseOwl. |
